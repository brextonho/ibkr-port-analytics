# IBKR Portfolio Analytics

A locally run dashboard for your Interactive Brokers account, in the
base currency the account uses. It pulls your daily
statements from IBKR, keeps them in a local SQLite file, and shows:

- **Overview**: net asset value, and how much of its change came from your
  deposits versus the market. Time-weighted return against pre-defined benchmark, both in your
  base currency.
- **Statistics**: exposure by asset class, currency, country or your own
  labels; risk and return figures against pre-defined benchmark; dividends and withholding tax.
- **FX**: your return split into what holdings did in their own currencies and
  what exchange rates added or took away.
- **Positions**: every holding plus cash. Drag a column header to group by it,
  and double-click to label holdings Core/Satellite, add a theme or a thesis.
- **Closed trades**: realized P&L and holding period of every sale, with notes.
- **Ops**: when data was last loaded, and any failed pulls.

Return figures are IB's own daily time-weighted returns, so deposits never show
up as performance. Everything runs on your machine; nothing leaves it except
the pulls from IBKR and benchmark prices from Yahoo Finance.

## Try it with demo data

You need [uv](https://docs.astral.sh/uv/getting-started/installation/) and
[Node.js](https://nodejs.org/) 20 or newer.

```bash
uv sync
npm --prefix web install
npm --prefix web run build
uv run portfolio ingest --demo
uv run portfolio serve --demo
```

Open http://localhost:8000. The demo is a fictional SGD account over one year
(October 2025 to September 2026), generated by `scripts/make_demo_xml.py`. The base currency is read from each statement. The tests run the same year as both SGD and USD accounts
(`tests/fixtures/`).

## Use it with your IBKR account

[SETUP.md](SETUP.md) walks through it: create the Flex query in IBKR (with a
checklist), add your token, load your history, and schedule daily pulls. It
also covers day-to-day running, troubleshooting and backups.

## Commands

| Command | What it does |
|---|---|
| `uv run portfolio ingest` | Pull the latest statements from IBKR (needs `.env`) |
| `uv run portfolio ingest --xml FILE...` | Load downloaded Flex XML files, in any order |
| `uv run portfolio serve` | Run the dashboard at http://localhost:8000 |
| `--demo` | Use the demo data (`demo.db`) instead of yours (`portfolio.db`) |
| `--db FILE` | Use another database file |
| `uv run pytest` | Run the tests, against the demo data in SGD and USD |
| `npm --prefix web run dev` | Live-reloading dashboard on :5173 (keep `serve` running) |
| `npm --prefix web run build` | Rebuild what `serve` hands out |
| `uv run python scripts/make_demo_xml.py` | Regenerate the demo data |

## Layout

| Path | What |
|---|---|
| `src/portfolio/` | Python: Flex client and parser, loader, analytics, API, CLI |
| `web/` | React dashboard (Vite, MUI, material-react-table, chart.js) |
| `config/config.example.yaml` | Optional settings: database file, benchmark, risk-free rate |
| `scripts/` | Demo data generator, schedule installer |
| `tests/` | pytest suite, run against the demo year |

Your data stays out of git: `.env`, `config/config.yaml`, `*.db` and
`data/` are all ignored.

## Known limits

- The FX breakdown weights currencies by holdings only. Cash in a foreign
  currency is left out, so the exchange-rate effect is slightly understated.
- There's no login: the dashboard listens on localhost only. Don't expose it
  to a network.
